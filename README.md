# Bio-Signal Analysis for Smoking

A machine-learning analysis project that explores biological-signal data to identify patterns associated with smoking status.

## Contents

| File | Description |
| --- | --- |
| `Biosignal Analysis for Smoking.ipynb` | Notebook for data exploration, preprocessing, and model analysis. |
| `smoking.csv` | Dataset used by the notebook. |

## Workflow

1. Load and inspect the bio-signal dataset.
2. Clean the data and prepare features for analysis.
3. Explore relationships between health indicators and smoking status.
4. Train and evaluate predictive models in the notebook.

## Requirements

Open the notebook with Jupyter Notebook or Google Colab and install the packages imported in the first cells.

## Disclaimer

This project is for educational data-analysis purposes only and is not medical advice or a clinical diagnostic tool.
